# Board Bite: INBDE study game

A free study game for the Integrated National Board Dental Examination (INBDE).

- **Arcade run:** 15 questions, 3 lives, streak multipliers, and speed bonuses
- **Flash recall:** spaced-repetition flashcards, weakest cards first
- **Match-up:** pair classic buzzwords with their answers against the clock

There are 136 original practice questions across 13 topic areas. Each question has an explanation and a memory hook. Progress is saved in your browser.

These are not official JCNDE questions. Practice the real exam format with the official sample questions at ADA.org/INBDE.

## Play
Open `index.html` in any browser, or visit the GitHub Pages link for this repository.
